# Kachi 当前约束

- 学习对象是易混淆词对；熟练度按词对统计，同一概念跨课程共用熟练度。课程来源、双语结构和新增内容门禁见 [词汇体系](vocabulary-system.zh-CN.md)。
- 界面采用浅色纸面；课程选择、词对教学、练习、补练和结果页构成核心路径。进度保存在本机 IndexedDB；导入必须验证完整记录，失败不得覆盖现有进度。
- 图片资源由 `content/art-manifest.json` 和 `public/art/` 管理；手绘课程使用 `src/art.tsx` 的图形，生成课程使用素材清单。两套调色规则及图片可达性均需保留。
- 单词音频在构建前生成，例句使用运行时语音。音频脚本的 DoH 解析和 `--resolve` 是请求路径的一部分；不要把生成能力描述为离线运行能力。
- 复习间隔为 1、3、7、14、30、60 天。补练不重复计入熟练度或 XP。
- `pnpm check` 执行 lint、内容校验、类型检查、单元测试、构建与产物校验；`pnpm test:e2e` 验证浏览器行为。发布使用仓库现有 Vercel 配置，构建产物为 `dist/`。

- 词义按 ID 区分，别名不另建概念。利润率 `margin` 与保证金 `margin-collateral` 分开；旧记录通过 `vocabularyRevision` 执行一次兼容迁移。入门课包位于第 0 级，原有六级编号和默认入口不变。

## 一、内容可信度

### 补齐溯源

`sources` 表已有 4 条一手来源（FINRA/SEC SBLOC、IRS Topic 409 等），但只被 3 个概念引用。
40 个概念里 37 个 `sourceIds: []`，26 个 `reviewStatus: "legacy"`。

schema 机制齐备（`sourceIds` / `risk` / `reviewStatus` / `rightsBasis`），缺的是内容：

1. 每个概念至少挂 1 条 `kind: "primary"` 来源；确实没有权威来源的（如 `buy-borrow-die`
   这类行业说法），`risk` 标 `jurisdictional` 并写明「这是流行说法而非监管定义」。
2. 定一个 `legacy → reviewed` 的可检验标准（谁复核、核什么、留什么记录）。
3. `scripts/validate-content.mjs` 加硬校验：`reviewStatus: "reviewed"` 必须有非空 `sourceIds`。

> T1（`t1-finance-news`）的 `sources: []` 是有意的，不是欠账：该包教的是标题里的高频词，
> 例句原创，不引用具体报道（见 `content/corpus/README.md`）。

### 引入「疑」题型

现有五题型（meaning/truefalse/fill/scenario/match）全是**回忆与辨识**，没有「审查一个论断
哪里站不住」。金融英语的真实场景就是读研报然后怀疑它。

加 `audit` 类：给一段含陷阱的短文本（单位错、区间偷换、幸存者偏差），让学习者揪出问题句。
`ExerciseType` 加一项，`why` 承担讲解。与现有 273 题池兼容。

### 题库密度

实测每概念被考次数：`hedge` 15、`pledge` 14、`short selling` 11；中位 6。
u1 每课 10 题，u3–u7 每课 8–9 题——前两单元承载了全部示例重量，后五单元（利率、曲线、基差
这些更难的）密度反而低。选一条并写进文档：补齐到均衡，或明说「前两单元是入门铺垫」。

## 二、视觉与空间

### 题目卡不要空着

实测 `.prompt` 卡内部空白：

| 题型    | 卡高  | 内容占 | 空白            |
| ------- | ----- | ------ | --------------- |
| teach   | 764px | 618px  | 146px (19%)     |
| meaning | 764px | 412px  | **352px (46%)** |
| fill    | 764px | 245px  | **519px (68%)** |

根因：`.prompt` 是 `flex: 1`，内容少时被拉伸填满。按优先级：

1. **让卡跟内容走**：内容不足时 `align-self: flex-start`，剩余空间留给反馈区。
2. **把留白变成内容**：fill 的 `bank` chip 放大成主视觉；meaning 的 tile 从 176×153 放大。
3. **teach-art 撑满**：容器 180px 高、SVG 只有 118px（填充率 57%）。

### 词汇表折叠

40 张卡 × 361px = 21.6 屏。默认折成一行（术语 + 中文 + 混淆词），点击展开对照台。
折叠后组头必须保留全信息；`ContrastBench` 的 `split` 状态要跨重绘保留。

### 学习路径折叠

23 张卡 = 3.8 屏。按单元折叠，默认展开「当前单元 + 下一课」。

### 中文标题的字体与字距

`--display` 是 Dela Gothic One，`unicode-range` 只覆盖拉丁，中文标题实际回落 PingFang，
却仍套着 `-0.045em` 负字距（34px 上 -1.53px）。中文标题应单独一条规则（正字距、显式黑体）。

## 三、产品差异化

### 音频（最大的缺口）

语言学习产品没有声音。全仓 0 音频、无 IPA 字段。

量级：40 术语 × 英/美 + 40 例句 ≈ 120 文件，估计 2–3MB，PWA 可整包 precache。

1. 先验 fish.audio 能否稳定出**可区分的英/美双音色**，不行退到单音色 + `speechSynthesis`。
2. 数据形状抄词光的 **media 位标记**（1 发音 / 2 例句 / 4 图片），前端按位判断有就播、
   没有就静默——为「渐进补资产」设计。
3. 加「听音辨词」题型。

### 错题本

`attempts` 是全量日志（含 `exerciseType` / `correct` / `conceptIds` / `latencyMs`），
目前只在结课屏显示最多 3 个 mix。可以做：

- 按混淆对聚合的历史错误率；
- 「你错过 3 次、最近一次在 5 天前」；
- 导出成可读的复盘清单。
